# 默契花火（hanabi）

经典双人合作 Hanabi 中文适配：不需要外部账号，不跳转第三方页面，复用小屋房间、按座位快照、重连、纪念册与重新开始。

## 来源与许可

参考 [bstnfrmry/hanabi / Hanab.cards](https://github.com/bstnfrmry/hanabi)，固定提交 [`9a9ce26ab14680cc48f7a105c32faec0cf002804`](https://github.com/bstnfrmry/hanabi/tree/9a9ce26ab14680cc48f7a105c32faec0cf002804)。上游 `src/lib/actions.ts` 支持两人每人五张、八提示、三次失误、正面与反面提示、打出五补提示、牌堆耗尽末轮。MIT，Copyright (c) 2020 Bastien Formery；完整原文保留于 `docs/licenses/Hanabi.txt` 与 `public/licenses/Hanabi.txt`，后者随静态构建分发且游戏内可查看。

这是基于上游规则行为的原生适配重写，不是 iframe / 原网站镜像：不复制 Firebase、登录、网站品牌素材或原全量客户端状态；只实现经典五色双人玩法，不含彩虹、多色、序列扩展、机器人或社区账号。与上游“理论可达分数耗尽即停”不同，本版只在25分、三次失误或末轮结束时终局。三次失误明确标为挑战失败，仍显示已点亮进度，不记个人胜场。

## 中文规则

- 红、黄、绿、蓝、白五色；每色1有三张，2/3/4各两张，5一张，共50张；每人五张，房主先行。
- 只看见伙伴牌面。自己的每张牌仅显示从提示获得的可能颜色、数字；不要线下直接报牌面。
- 每回合任选一个动作：给伙伴提示、打出自己的牌、弃掉自己的牌。
- 提示消耗一个提示，须选择伙伴确实持有的颜色或数字，同时标出**所有**匹配牌。未匹配牌也排除这个颜色/数字。新抽牌不会继承旧牌提示。
- 每色烟花只能按1到5递增。打错丢弃该牌并消耗一根引线；第三次失误立即结束。打出5在提示未满时恢复一个。
- 弃牌恢复一个提示，提示最多8个；满提示时禁止弃牌。
- 抽走最后一张后，接下来两位玩家各有一个回合（任何动作，包括提示，都算）；随后结束。25分立即完美结束，不再补牌。
- 断线没有计时惩罚：双方重连后继续原回合；断线期间服务器拒绝游戏动作。

## 数据与隐私

服务端 `data`：`phase / turn / turnNumber / hints / fuses / fireworks / deck / hands / discard / log / score / finalTurns / endReason`。

`deck` 只有服务端持有，洗牌使用 Node crypto 无公开种子。牌抽入手牌时生成随机 UUID，不能由 ID 推导牌色、数字或预洗牌位置。每张手牌 `{id,color,rank,knowledge:{colors,ranks}}`；提示只收缩候选集合。

`view(data, seat)` 使用明确白名单，牌堆只返回 `deckCount`；该座位手牌永不返回 `color/rank`（结算亦然），只返回随机 ID 与已获得的提示知识；对方牌可见。非法/未指定座位看不到任何手牌面。日志只有已出牌/已弃牌、公开提示及结算；只保留20条，不记录新抽牌。共享纪念册仅保存总分、五色进度、结束原因、回合数，无牌堆/手牌/种子。新增字段不可通过对象展开意外暴露。

## 动作契约

所有动作必须带 `{run: room.game.run, turnNumber: data.turnNumber}`，通过当前座位和连接状态校验后才操作。

- `{type:'hint',kind:'color'|'rank',value}`：目标隐式为伙伴；可选target必须恰为另一座位。拒绝空提示/未知值/零提示。
- `{type:'play'|'discard',cardId}`：只接受当前自己手牌的稳定ID，不接受数组索引，拒绝旧牌/对手牌。
- `turnNumber` 每个成功动作加1，拒绝失败的动作完全不修改状态。旧run/旧回合重放不会误操作新牌。
- `finalTurns` 抽空前为null，抽空那回合设为2、不立刻减；之后每成功动作减1。无需 `tick()`，没有后台暗走回合。

## 实现与测试

七个模块遵循自动发现约定，独立 CSS 无公共框架改动。中文UI有颜色文字+图形辅助、提示命中预览与确认、自牌选择后明确出牌/弃牌操作、规则、弃牌区与公开日志；中央 GameStageHost 负责结算。

```bash
npm run test:game -- hanabi
npm run smoke:game -- hanabi
npm run build
npm test
npm run smoke
```

单测覆盖牌数、正反线索、非法动作无变更、服务器双方脱敏/字段白名单、失误/25分、提示上限、补牌知识重置、最后两回合、JSON恢复与旧牌拒绝。双WebSocket冒烟验证真实帧双视角隐藏、提示同步、断线重连欢迎快照、完整对局结束、历史API、重开和旧run拒绝。机器人只通过伙伴客户端合法可见牌面选牌，不读取服务端秘密。
